# 客户邮件分类

## 5 类别定义

| 类别 | 信号词 | 核心特征 |
|------|--------|---------|
| 投诉 | 不满/失望/故障/坏了/糟糕 | 表达负面情绪 |
| 建议 | 建议/希望/改进/能否 | 建设性意见 |
| 咨询 | 请问/怎么/如何/什么时候 | 询问信息 |
| 表扬 | 感谢/满意/喜欢/推荐 | 正面情绪 |
| 其他 | — | 不属于上述 4 类（合作、求职、营销等） |

## 规则

1. 情绪优先：含负面情绪词 → 投诉；含正面情绪词 → 表扬
2. 意图次之：提改进意见 → 建议；纯询问 → 咨询
3. 多种意图时选**最主要**的那个

## 输出格式（严格遵守）

只输出 JSON，不要任何解释：

```json
{"category": "投诉|建议|咨询|表扬|其他", "reason": "一句话理由"}
```
