# 任务: 邮件分类（5类）

## 类别

- **投诉**: 负面情绪（不满/坏了/差）
- **建议**: 改进意见（建议/希望）
- **咨询**: 信息询问（请问/怎么）
- **表扬**: 正面情绪（感谢/满意）
- **其他**: 其他

## 输出

仅输出 1 行 JSON，无其他字符：

`{"c":"投诉|建议|咨询|表扬|其他","r":"≤15字理由"}`

## 示例

| 输入摘要 | 输出 |
|---------|------|
| "你们的产品太差了，根本不能用" | `{"c":"投诉","r":"产品故障+不满"}` |
| "希望能增加夜间配送服务" | `{"c":"建议","r":"提改进意见"}` |
| "我的订单什么时候发货？" | `{"c":"咨询","r":"询问物流时间"}` |
| "客服小李服务非常好，谢谢！" | `{"c":"表扬","r":"称赞客服态度"}` |
| "贵公司是否接受商业合作？" | `{"c":"其他","r":"合作邀约"}` |

## 约束

- 不要任何前言/后语
- 不要解释/分析过程
- 严格 JSON 格式
