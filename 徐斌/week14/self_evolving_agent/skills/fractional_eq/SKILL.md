# 分式方程的实际应用

## 输出名称（必须一字不差）
分式方程的实际应用

## 触发特征
- 含时间/效率/单价比较表述：如“每千克贵x元”“每天多生产x个”“速度是…倍”“早x分钟到达”“所用时间相同”
- 设x后方程为分式结构：A/x = B/(x±c) 等
- 场景词：购进水果、加工零件、搬运货物、步行上学、超市进货、工厂生产

## 反例（不要匹配）
- 纯整式方程（如3x+5=20）或一元一次方程应用题
- 无实际场景的纯解分式方程计算题
- 方程不含分式结构（如未出现分母含未知数）
