# 勾股定理

## 输出名称（必须一字不差）
勾股定理

## 触发特征
- 含直角三角形/矩形/菱形/平行四边形，且出现坐标、长度、距离、中点、斜边等词
- 隐含直角：如∠OAB=90°；OA=AB且∠OAB=90°；BD∥x轴+菱形→对角线垂直；∠AOC=45°且OA=2√2→可得直角边
- 求k、点坐标、边长等，需设未知数并列a²+b²=c²方程

## 反例（不要匹配）
- 无几何背景的纯代数方程题
- 明确要求用相似三角形、三角函数、面积法等非勾股方法的题
