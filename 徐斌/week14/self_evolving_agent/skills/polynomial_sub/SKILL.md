# 整式代入求值

## 输出名称（必须一字不差）
整式代入求值

## 触发特征
- 含“先化简，再求值”“化简后求值”“当…时，求…的值”等指令
- 表达式为纯多项式（无分母/根号/绝对值/对数），含括号、系数、幂次；代入值为具体数（含分数、负数）

## 判定提示
- 必须执行：去括号 → 合并同类项 → 代入 → 计算
- 未要求化简，或已化简直接代入，均不匹配

## 反例（不要匹配）
- 含分式、根号、绝对值、对数等非整式结构
- 仅“求值”无“化简”要求，或已给化简结果
