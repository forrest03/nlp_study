# ReAct 金融分析 Agent 使用指南

本文档详细介绍 `react_manual.py`（手写 Prompt 解析版）和 `react_function_calling.py`（Function Calling API 版）的使用方法。

---

## 一、快速开始：交互式多轮会话

### 1.1 react_manual.py

```bash

python react_manual.py
```

运行后进入交互模式，支持多轮上下文理解：

```bash
# 启动交互式多轮会话
python react_function_calling.py
```

运行效果与 `react_manual.py` 类似，但使用 Function Calling API 实现：

```

```

## 二、环境准备

### 2.1 安装依赖

```bash
pip install openai faiss-cpu sentence-transformers akshare
```

### 2.2 配置 API Key

根据使用的模型，设置相应的环境变量：

#### 方式一：使用阿里云 DashScope（qwen-max）

```bash
# Linux/Mac
export DASHSCOPE_API_KEY="sk-xxx"

# Windows PowerShell
$env:DASHSCOPE_API_KEY="sk-xxx"
```

#### 方式二：使用 DeepSeek（deepseek-v4-flash）

```bash
# Linux/Mac
export DEEPSEEK_API_KEY="sk-xxx"

# Windows PowerShell
$env:DEEPSEEK_API_KEY="sk-xxx"
```

**注意**：`react_manual.py` 默认使用 DashScope，`react_function_calling.py` 默认使用 DeepSeek。如需切换，可修改代码中的客户端配置。

## 三、命令行参数

### 3.1 react_manual.py

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--question` | string | None | 初始问题（支持多轮会话） |
| `--max_steps` | int | 10 | 最大推理步数 |
| `--interactive` | flag | False | 强制进入多轮会话模式 |

### 3.2 react_function_calling.py

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--question` | string | None | 初始问题（支持多轮会话） |
| `--max_steps` | int | 10 | 最大推理步数 |
| `--interactive` | flag | False | 强制进入多轮会话模式 |

## 四、使用示例

### 4.1 指定初始问题

```bash
# react_manual.py
python react_manual.py --question "茅台和五粮液2023年毛利率差多少？"

# react_function_calling.py
python react_function_calling.py --question "贵州茅台过去一年股价涨跌幅是多少？"
```

回答完初始问题后，程序会继续等待用户输入，支持多轮会话。

### 4.2 指定最大步数

```bash
python react_manual.py --question "茅台近一年股价涨跌幅如何？" --max_steps 8
```

### 4.3 单轮问答后退出

```bash
python react_manual.py --question "贵州茅台的PE是多少？"
```

**注意**：当指定 `--question` 参数但不指定 `--interactive` 时，程序执行单轮问答后自动退出。

## 五、支持的工具

| 工具名称 | 功能描述 |
|---------|---------|
| `company_lookup(name)` | 将公司名称转换为股票代码 |
| `financial_indicator(symbol)` | 获取实时财务指标（PE/PB/ROE等） |
| `stock_price(symbol, start_date, end_date)` | 获取历史股价数据 |
| `calculator(expr)` | 计算数学表达式 |
| `rag_search(query)` | 在年报中语义检索文本内容 |

---

## 六、两种实现的对比

| 特性 | react_manual.py | react_function_calling.py |
|------|-----------------|--------------------------|
| **实现方式** | 手写 Prompt + 正则解析 | Function Calling API |
| **Thought 可见性** | 可见（可调试） | 不可见（模型内部） |
| **格式控制** | 需要严格 Prompt 约束 | 框架自动处理 |
| **稳定性** | 依赖 Prompt 质量 | 更稳定可靠 |
| **默认模型** | qwen-max (DashScope) | deepseek-v4-flash |

## 八、注意事项

1. **工具调用顺序**：使用 `financial_indicator` 或 `stock_price` 前，必须先用 `company_lookup` 获取股票代码
2. **数字计算**：涉及数学计算时，系统会自动调用 `calculator` 工具
3. **数据来源**：最终回答会引用具体数据来源（AkShare实时数据或年报）
4. **退出方式**：在交互模式下输入 `exit`、`quit` 或 `bye` 退出程序
5. **多轮会话**：系统会自动保存对话历史，支持上下文理解

## 九、故障排除

### 常见问题

1. **API Key 错误**：确保已正确设置环境变量
2. **工具调用失败**：检查网络连接和 AkShare 数据接口
3. **格式解析失败**：确保模型输出符合预期格式
4. **达到最大步数**：增加 `--max_steps` 参数值

### 日志查看

程序使用 `logging` 模块记录日志，默认级别为 WARNING。如需详细日志，可修改代码中的日志配置：

```python
logging.basicConfig(level=logging.DEBUG)
```
