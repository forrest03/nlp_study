# GRPO 算术题训练结果分析报告

## 一、实验概述

本实验基于 **GRPO（Group Relative Policy Optimization）** 算法，使用 Qwen2.5-0.5B-Instruct 模型进行算术推理能力训练。训练集覆盖 6 个难度级别，采用复合奖励函数（正确率分 + 格式分），对比全量微调与 LoRA 微调两种方案的效果差异。

### 1.1 模型与训练配置

| 项目 | 配置 |
|------|------|
| 基础模型 | Qwen2.5-0.5B-Instruct |
| 训练算法 | GRPO (Group Relative Policy Optimization) |
| 优化器 | AdamW |
| 学习率 | 线性衰减 (起始 ~2e-6, 终态 ~1e-8) |
| K (组内采样数) | 8 |
| 训练步数 | 200 |
| 奖励函数 | reward_correct (权重1.0) + reward_format (权重0.2) |

### 1.2 难度级别定义

| 级别 | 类型 | 示例 | 训练集占比 |
|------|------|------|-----------|
| L1 | 个位数加法 | 2 + 1 | 5% |
| L2 | 两位数加减 | 54 + 85 | 25% |
| L3 | 三位数加减 | 757 - 655 | **50%** (主训) |
| L4 | 表内乘法 | 5 × 5 | 5% |
| L5 | 两位×一位 | 88 × 5 | 25% |
| L6 | 两位×两位 | 38 × 14 | 0% (仅测试) |

### 2.4 信息组率（Informative Group Rate）

Informative Group Rate 衡量组内存在优势差异的比例（即不是全对或全错的组）。比例越高，说明该难度越能提供有效的训练信号。

| 难度级别 | 基线 | 全量微调 | LoRA微调 |
|----------|------|----------|----------|
| L1 | 0.130 | 0.542 | 0.040 |
| L2 | 0.324 | 0.550 | 0.096 |
| L3 | 0.398 | 0.624 | 0.226 |
| L4 | 0.138 | 0.472 | 0.062 |
| L5 | 0.300 | 0.544 | 0.214 |
| L6 | 0.072 | 0.324 | 0.288 |

**关键洞察：**
- 基线时各难度的信息组率较低（0.07–0.40），大部分组要么全对要么全错
- 全量微调后信息组率有所提升（0.32–0.62），说明模型的能力分布更加分化
- LoRA 微调后信息组率大幅下降（多数 <0.1），因为 LoRA 模型几乎全部答对，组内无差异
- **L6 始终保持较低的信息组率**（0.07 → 0.32 → 0.29），说明模型在该难度上始终"要么会要么不会"，难以产生渐进式进步

## 四、核心发现与教学要点

### 4.1 格式学习先于正确率收敛

**现象：** 两种微调方案中，格式分均在训练早期即收敛（Step 10–30），而正确率分需到 Step 100–115 才接近最终值。

**GRPO 原理：** 复合奖励函数中，格式分（0.2）作为"学习拐杖"，为模型提供密集的反馈信号。即使模型还不会正确计算，只要学会输出 `<answer>` 标签，就能获得部分奖励。这体现了 **奖励塑形（Reward Shaping）** 的设计思想——将困难任务分解为更易学习的子技能。

### 4.2 LoRA 微调全面优于全量微调

**现象：** LoRA 在所有难度、所有指标上均领先，尤其在 L5（两位×一位）上准确率达 97.2%（全量为 90.0%）。

**GRPO 原理：** LoRA 仅训练注意力层的低秩适配器（rank=16），相当于对模型施加了 **隐式正则化**：
- 限制了参数更新的自由度，防止对训练集的过拟合
- 保留了预训练模型的大部分知识，在 RL 训练中更稳定
- 组内优势的归一化计算在低维参数空间中更加有效

### 4.3 L6（两位×两位）始终是能力瓶颈

**现象：** 即使经过训练，全量和 LoRA 在 L6 上的准确率仍仅 24.8% 和 28.4%，远低于其他难度。

**GRPO 原理：** 
- L6 需要掌握多位数乘法的分步计算（进位、部分积累加），超出 0.5B 模型的推理能力边界
- **信息组率** 在 L6 上始终较低（0.07 → 0.32 → 0.29），说明模型对这类题目"要么会要么不会"，无法产生渐进式的优势信号
- 验证了训练集难度配比的合理性：L6 仅作为测试集（0% 训练占比），主训聚焦于"可学习甜区"（L3/L5/L2）

### 4.4 后期训练无效，应早停

**现象：** 
- 全量微调在 Step 115 后零优势组占比 > 50%，奖励进入平台期
- LoRA 微调在 Step 50 后零优势组占比 > 90%，Step 100 后达 100%

**GRPO 原理：** 
- GRPO 通过组内 K 个样本的优势归一化来计算梯度，当组内全部答对（或全部答错）时，优势值为 0，梯度为 0
- 当 `frac_reward_zero_std` 超过 50% 时，超过一半的组无法提供有效训练信号
- **建议早停点：Step 100–150（全量）/ Step 50–100（LoRA）**，可节省约 50% 的训练时间

## 五、GRPO 核心知识点总结

| 观察现象 | 对应 GRPO 核心知识点 |
|----------|---------------------|
| 格式分先于正确率收敛 | **复合奖励塑形**：格式分作为辅助奖励，降低任务难度，引导模型逐步学习 |
| LoRA 优于全量微调 | **参数效率微调**：低秩约束作为隐式正则化，在 RL 中提供更稳定的优化路径 |
| 训练集难度配比 L3(50%)/L5(25%)/L2(25%) | **难度课程设计**：聚焦"可学习甜区"，最大化组内优势差异 |
| 后期熵值→0 + 零优势组→1 | **早停机制**：信息组率下降是训练停滞的信号 |
| L6 始终低准确率 | **能力边界认知**：RL 无法超越模型的预训练能力上限，需要更大模型或专项数据 |
| Pass@k 远高于 greedy accuracy | **采样多样性**：GRPO 利用多样采样来探索模型的潜在能力上限 |

## 六、结论与建议

### 6.1 主要结论

1. **LoRA 是 0.5B 模型的优选方案**：在准确率、收敛速度和最终奖励上全面超越全量微调，参数更新量仅为全量的极小部分
2. **复合奖励设计有效**：格式分（0.2）和正确率分（1.0）的组合成功实现了"先格式后正确率"的渐进式训练动态
3. **GRPO 优势归一化机制有效**：通过组内 K=8 样本的归一化，有效平衡了不同难度样本的训练信号
4. **模型能力边界明显**：Qwen2-0.5B-Instruct 难以掌握两位数乘法（L6），需更大模型或专项训练数据

### 6.2 改进建议

| 优化方向 | 具体建议 | 预期效果 |
|----------|----------|----------|
| **早停策略** | 在 `frac_reward_zero_std > 0.5` 时停止训练 | 节省 ~50% 训练时间 |
| **模型规模** | 升级到 1.5B+ 模型 | L6 准确率有望突破 50% |
| **奖励设计** | 增加中间过程分（如分步骤得分） | 为 L6 等复杂任务提供更密集的反馈 |
| **LoRA 配置** | 尝试不同 rank（8/32/64）对比 | 探索参数效率与性能的最优平衡点 |
| **难度扩展** | 训练集中加入 L6 样本，使用课程学习 | 逐步引导模型掌握两位数乘法 |
| **K 值调优** | 尝试 K=4/16 对比 | 探索组大小对训练动态的影响 |
